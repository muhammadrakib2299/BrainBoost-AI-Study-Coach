Core features (MVP)

PDF / note upload + image OCR

Upload PDFs, paste text, or link a URL. AI parses text, diagrams, tables, and handwritten notes using Claude's vision to extract key concepts automatically.

AI flashcard generator

Automatically creates Q&A flashcards from your content. Edit, regenerate, or export any deck to Anki (.apkg) or printable PDF.

Smart quiz mode

Multiple choice, true/false, fill-in-the-blank, and essay-type quizzes with AI grading. Includes timed mode for exam simulation.

FSRS spaced repetition

FSRS algorithm (successor to SM-2, more accurate) schedules reviews based on how well you know each card. Hard cards come back sooner.

Study schedule + calendar sync

Set your exam date. AI builds a day-by-day study plan prioritizing weak topics. Syncs to Google Calendar / iCal so study blocks appear in your real schedule.

Progress dashboard + exam readiness

Track mastery per topic, daily streaks, quiz scores, and time studied. Includes a predicted exam readiness score — "You're ~72% ready."

AI tutor chat

Persistent AI chat per topic — ask follow-up questions, request analogies, or say "explain like I'm 5." A real tutor, not just flashcards.

Summary generator

One-click summaries in multiple formats — brief/medium/deep, Cornell Notes, or visual mind map output.

Active recall writing

After reviewing a topic, write what you remember from memory. AI compares your response against source material and scores completeness.

Weak spot drills

AI analyzes your mistake patterns — confusing similar terms, missing edge cases — and generates targeted drill sets that attack specific weaknesses.

Post-MVP features (Phase 2)

Collaborative study rooms

Share decks, quiz each other in real-time, and study the same material together. Group leaderboards and shared progress tracking.

Concept map / knowledge graph

Auto-generated visual map showing how concepts relate. See gaps — "you've mastered X but haven't studied Y, which depends on X."

Voice input / audio notes

Record lectures or explain concepts aloud. Whisper API transcribes, AI generates cards. Audio-based review for studying on the go.

Multi-format export

Export decks to Anki (.apkg), printable PDF study sheets, or shareable links. Reduces lock-in and drives adoption through sharing.

MVP build roadmap

1

Week 1 — Upload + parse + image OCR

File upload UI, PDF text extraction, Claude Vision for diagrams/tables/handwriting, store raw content in DB, basic auth with Supabase.

2

Week 2 — AI flashcard generation + tutor chat

Claude API prompt to extract concepts and generate Q&A pairs. Display, edit, and save flashcard deck. Persistent AI tutor chat per topic.

Multiple choice, essay-type, and timed quizzes. Active recall writing mode. Score tracking, AI explanation on wrong answers, weak spot analysis.
